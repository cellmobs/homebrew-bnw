# Homebrew tap for BNW

```bash
brew install cellmobs/bnw/bnw
bnw setup
```

`bnw setup` creates this device's identity, starts the node at login, and opens the web client. To run the node as a Homebrew service instead, use `brew services start bnw`; use one or the other.

Release builds and the other ways to install are at [cellmobs/bnw-releases](https://github.com/cellmobs/bnw-releases).
